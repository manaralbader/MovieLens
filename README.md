# Movie Ratings Mini-Lakehouse

A small Bronze → Silver → Gold lakehouse pipeline (Spark + Delta Lake) built
on real movie rating data, as a hands-on way to verify understanding of
modern data engineering concepts. See [PROJECT_BRIEF.md](PROJECT_BRIEF.md)
for the full plan.

## Dataset credit

This project uses the **MovieLens** dataset, collected and maintained by
[GroupLens Research](https://grouplens.org/datasets/movielens/), University
of Minnesota. Downloaded via the
[Kaggle mirror](https://www.kaggle.com/datasets/sriharshabsprasad/movielens-dataset-100k-ratings)
of `ml-latest-small`.

> History and Context. *ACM Transactions on Interactive Intelligent Systems*
> 5, 4: 19:1–19:19. https://doi.org/10.1145/2827872
